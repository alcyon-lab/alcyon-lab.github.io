Graph coloring can be written as an integer linear program in several ways (assignment, representatives, set covering, …), and the choice of formulation strongly affects solver performance.

## Goal

Implement several formulations with an open-source solver, run them on standard benchmark graphs, and explain the differences in running time and in the strength of their linear relaxations.
