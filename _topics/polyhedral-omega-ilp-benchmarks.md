Polyhedral Omega computes rational generating functions of the integer points of polyhedra and can be used to solve integer linear programs (POGA project; ISSAC 2024 software presentation).

## Goal

Run Optimization.jl on standard integer programming benchmark families, compare it with branch-and-bound solvers, and identify the problem structures where the generating-function approach is competitive.
